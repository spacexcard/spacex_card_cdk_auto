## 2. 卡台接口（权威）

文档：`docs/spacexcard-cdk-zh.md`、`docs/spacexcard-openapi-zh.md`。

### 公开兑换（无需登录）

| 步骤 | 方法 | 路径 |
|------|------|------|
| 预览 | POST | `/api/v1/cdk/preview` |
| 预检 | POST | `/api/v1/cdk/preflight` |
| 兑换 | POST | `/api/v1/cdk/redeem` |
| 结果 | GET | `/api/v1/cdk/result?token=` |

Base 示例：`https://spacexcard.com`

### 程序化发码 / 对账（Open API）

- Base：`https://spacexcard.com/openapi/v1`
- Header：`X-API-Key: sk_…`
- 发码：`POST /gpt-direct/cdks`
- 列码：`GET /gpt-direct/cdks`
- 兑换订单：`GET /gpt-direct/cdk-orders`

本站配置（`site_settings` /「卡台接入」）：

- `card_api_base`
- `card_api_key`（只写，读脱敏）

## 4. 安全注意

若曾把 `.env` / `.push.env` / 生产 JWT / 卡台 Key 推到公开仓库：

1. **立即轮换**所有泄露密钥（CF token、PAT、JWT_SECRET、卡台 sk、Webhook secret）。
2. 确认 `.gitignore` 含：`.env`、`.push.env`、`data/*.db`、`*.pem`。
3. 生产密钥只写服务器 `app.env`。
