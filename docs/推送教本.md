# Git 推送教本（配置 PAT 后一键推）

> 仓库：https://github.com/spacexcard/spacex_card_cdk_auto  
> 提交显示名：**spacexcard**（与 GitHub 登录账号可以不同）  
> 推送账号：对 `spacexcard` 组织有写权限的 GitHub 账号（用 PAT 证明）

---

## 0. 30 秒理解

| 概念 | 是什么 | 配在哪 |
|------|--------|--------|
| **PAT** | 推代码时的「密码」 | `.push.env` 里的 `GIT_PAT` |
| **作者 spacexcard** | 网页上每条 commit 显示谁写的 | `.push.env` 里的 `GIT_AUTHOR_*` |
| **push** | 把本地代码传到 GitHub | 运行 `./scripts/push.sh` |

**PAT 不会进 git 历史**（`.push.env` 已在 `.gitignore`）。

---

## 1. 第一次：创建 PAT

1. 用对 **spacexcard** 组织有写权限的账号登录 GitHub  
2. 打开：https://github.com/settings/tokens/new  
3. Note 随便写：`cdk-push`  
4. 勾选：**`repo`**（若组织启用 SSO，点 Authorize 授权组织）  
5. Generate → 复制 `ghp_...`（只显示一次）

---

## 2. 第一次：写配置文件（默认放 PAT 的地方）

在仓库根目录执行：

```bash
cd .

cp .push.env.example .push.env
```

用编辑器打开 `.push.env`，改成例如：

```bash
GIT_USER=spacexcard
GIT_REPO=spacex_card_cdk_auto
GIT_PAT=ghp_把你复制的token粘这里
GIT_AUTHOR_NAME=spacexcard
GIT_AUTHOR_EMAIL=spacexcard@users.noreply.github.com
GIT_BRANCH=master
```

保存。  
**不要**把 `.push.env` 发到聊天、不要 `git add .push.env`。

本地远程已指向：

```text
https://github.com/spacexcard/spacex_card_cdk_auto.git
```

（`git remote -v` 可确认）

---

## 3. 日常：改代码后推送

```bash
cd .

# 1）看改动
git status

# 2）提交
git add -A
git status   # 确认没有 .push.env、没有 data/*.db
git commit -m "说明你这次改了什么"

# 3）一键推送（自动读 .push.env 里的 PAT）
chmod +x scripts/push.sh
./scripts/push.sh
```

若远程是空仓库或历史已清空、需要覆盖：

```bash
./scripts/push.sh --force
```

成功后浏览器打开：  
https://github.com/spacexcard/spacex_card_cdk_auto

---

## 4. 脚本内部做了什么（对照学习）

`scripts/push.sh` 相当于：

```bash
set -a; source .push.env; set +a
git remote set-url origin "https://github.com/${GIT_USER}/${GIT_REPO}.git"
git push "https://${GIT_USER}:${GIT_PAT}@github.com/${GIT_USER}/${GIT_REPO}.git" master
```

---

## 5. 安全注意

1. `.push.env` 永不提交  
2. PAT 泄露 → 立刻打开 https://github.com/settings/tokens **Delete**，再新建  
3. 不要把 `ghp_` 写进教本、README、截图  
4. 推送前确认无 `session.json` / `*.db` / 真实密钥

---

## 6. 手动推送（不用脚本时）

```bash
set -a; source .push.env; set +a
git remote set-url origin "https://github.com/${GIT_USER}/${GIT_REPO}.git"
git push "https://${GIT_USER}:${GIT_PAT}@github.com/${GIT_USER}/${GIT_REPO}.git" master
```
