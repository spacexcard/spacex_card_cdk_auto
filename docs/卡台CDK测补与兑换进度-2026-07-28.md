# 卡台 CDK 测补 & 兑换进度（白标侧）

权威卡台文档见 sibling：`cardplatform/docs/CDK订单对账与进度测补-2026-07-28.md`。

## 本站相关

| 功能 | 路径 |
|------|------|
| 兑换对账 | `/ops/orders` |
| 用户兑换 + 进度时间线 | `/recharge` |
| 结果轮询 BFF | `GET /api/v1/public/cdk/result?token=` |

## 进度是否「实时」

- **不是** WebSocket 推送。
- **是** 每约 3 秒轮询卡台 `result`，展示 `order.status` / `order.stage` / `order.message` / `events[]` 时间线。
- 与卡台网页 GPT 直充时间线**同源数据**；终态 Webhook 只推 `gpt_direct.completed`。

## 验收

1. 提交兑换后第 4 步出现「处理明细」时间线（有 events 时）。
2. 状态变为 `completed` 后轮询停止。
3. 管理端对账列表与卡台订单一致。
