# 删除 ChatGPT 已绑定支付卡片

来源:抓包 `chatgpt.com.har`。删除绑定卡片就是对 `payments/payment_method/{pm_id}` 发一个 **DELETE**,成功返回 `{"success":true}`。流程是「先列卡拿 `pm_` id → 再删」。

## 接口

### ① 列出已绑卡片
```
GET https://chatgpt.com/backend-api/payments/payment_methods?account_id={account_id}
```
响应:
```json
{ "payment_methods": [ { "id": "pm_xxx", ... } ],
  "default_payment_method_id": null,
  "backup_payment_method_enabled": null }
```

### ② 删除指定卡片
```
DELETE https://chatgpt.com/backend-api/payments/payment_method/{pm_id}?account_id={account_id}
```
- 无请求体,参数全在 URL
- 响应:`{"success":true}`

## 参数来源

| 参数 | 来源 |
|---|---|
| `account_id` | session JSON 的 `account.id`;或 accessToken 解码后 `https://api.openai.com/auth.chatgpt_account_id` |
| `{pm_id}` | 列卡接口返回的 `payment_methods[].id`(形如 `pm_1TXhIs...`) |

## 鉴权

`Authorization: Bearer <accessToken>`(与 checkout/check 同一套)。
HAR 里是浏览器登录态(cookie),导出时被抹掉了;编程调用用 Bearer 即可。

## Cloudflare 说明

`chatgpt.com/backend-api/*` 在 Cloudflare 后。实测 **Python `requests`(HTTP/1.1 + OpenSSL 指纹)能直接通过**,而 Go `net/http` / `curl` 会被 403。所以本目录的 `delete_card.py` 用 `requests` 直连即可;若哪天被拦,改走后端 tls-client 路径。

## 用法(配套脚本 `delete_card.py`)

```bash
pip install requests   # 仅首次

# 列出该账号已绑卡片
python3 delete_card.py session.json --list

# 列出并交互确认后删除全部
python3 delete_card.py session.json

# 删除全部、不确认
python3 delete_card.py session.json --all --yes

# 只删指定卡
python3 delete_card.py session.json --pm pm_1TXhIs...
```

`session.json` 为从 `https://chatgpt.com/api/auth/session` 取的完整 JSON;也可直接把 accessToken 字符串作为第一个参数。

## 用途

账号「已绑卡」时,结账页显示的是已存卡、不出新卡输入框。**先删掉已绑卡,结账页就回到"新增卡"表单**,自动填表脚本即可继续填新卡。

> ⚠️ 仅在你拥有/已授权的账号上操作。
